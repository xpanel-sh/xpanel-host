# Política de seguridad

## Versiones compatibles

| Versión | Correcciones de seguridad |
| --- | --- |
| Rama `main` | Sí, durante el desarrollo activo |
| Versiones etiquetadas | Todavía no existen versiones estables |

## Reportar una vulnerabilidad

Envía el reporte de forma privada mediante [GitHub Security Advisories](https://github.com/xpanel-sh/xpanel-host/security/advisories/new). No abras un issue, discusión o pull request público antes de coordinar la divulgación.

Incluye, cuando sea posible, la versión o commit afectado, impacto, pasos reproducibles, una prueba de concepto mínima y cualquier mitigación conocida. No incluyas datos de terceros.

Intentaremos confirmar la recepción en 3 días hábiles, realizar una primera evaluación en 7 días hábiles y compartir avances al menos cada 14 días mientras el caso siga abierto. Estos plazos son objetivos de respuesta, no un acuerdo de nivel de servicio.

## Investigación responsable

Limita las pruebas a sistemas y datos que controles. No destruyas información, interrumpas servicios, mantengas acceso persistente ni vulneres la privacidad. Haremos un esfuerzo de buena fe por colaborar con investigaciones que respeten estas reglas.
