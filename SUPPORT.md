# Soporte

XPanel Host está en desarrollo activo y todavía no ofrece soporte con tiempos garantizados.

- Para errores reproducibles o propuestas concretas, utiliza las plantillas de [GitHub Issues](https://github.com/xpanel-sh/xpanel-host/issues/new/choose).
- Antes de abrir un issue, busca si ya existe uno similar y adjunta versión, sistema operativo, registros relevantes y pasos de reproducción sin secretos.
- Las preguntas generales de administración de servidores pueden quedar fuera del alcance del proyecto.
- Para vulnerabilidades, sigue exclusivamente [SECURITY.md](SECURITY.md).

La disponibilidad de un mantenedor o una respuesta en un issue no implica soporte administrado para servidores de producción.
